# Company Website & SEO

## Website role

The BAHNES website should:
1. Generate qualified inquiries for IT Infrastructure & Security and Software & Digital Solutions.
2. Establish trust through accurate work examples, clear delivery practices, and useful Insights.
3. Present validated software products and website templates in a curated catalog.

The website is planned; this document does not imply it has been built or launched.

## Proposed navigation

- Home
- Services: IT Infrastructure & Security; Software & Digital Solutions; individual service pages
- Our Work / Case Studies
- Products
- Website Templates
- Insights
- About
- Contact / Start a Project
- Privacy and other required legal pages after review

Do not fill empty sections with fake projects or stock images presented as real customer work.

## Homepage essentials

A clear positioning statement, two visible service-line paths, genuine proof or explicitly labelled demos, a credible delivery process, featured products/templates only when ready, useful Insights, and a clear project/contact CTA.

## Experience requirements

- Laravel Blade server-rendered pages as the planned baseline; no SPA requirement.
- Arabic and English with correct RTL/LTR behavior.
- Fully considered light and dark themes, not a blind color inversion.
- Responsive, accessible, keyboard-operable layouts and reduced-motion support.
- Purposeful motion only; avoid heavy 3D and animations that hurt speed or clarity.
- Optimized images, sensible caching, small script payloads, clear form states, and robust error handling.

## CMS scope

The admin should manage pages and defined sections, services, projects/case studies, products, website templates, Insights/articles, media, translations, contact and sales inquiries, and SEO fields. Use a controlled set of reusable section types rather than a universal drag-and-drop builder.

## SEO baseline

Unique titles/descriptions per language, canonical URLs, reciprocal hreflang links, a correct XML sitemap and robots directives, Open Graph preview data using the approved brand asset, appropriate structured data only when accurate, useful internal links, descriptive alt text, correct redirects, and a useful 404 page.

## Measurement

Track qualified inquiries, service-line interest, project form completion, product/template demo requests, inquiry source, and useful page engagement with privacy-aware measurement. Minimize personal data collection.

## Launch checklist

- [ ] Service descriptions, scope, support terms, and contact details approved.
- [ ] English and Arabic reviewed.
- [ ] Themes, RTL/LTR, keyboard, mobile, and reduced-motion behavior checked.
- [ ] Forms, notifications, validation, spam controls, and privacy text tested.
- [ ] Metadata, canonical, hreflang, sitemap, robots, Open Graph, and redirects validated.
- [ ] Social previews use the actual approved logo/brand image.
- [ ] Work examples are authorized and accurately labelled.
- [ ] Backup, deployment, rollback, and ownership documented.
